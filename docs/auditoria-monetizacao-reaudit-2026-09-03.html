Achados — status

FEITO Trial unificado em 7 dias

Fonte canônica config/plan-limits.json → trialDays. FE (TRIAL_DAYS), Express (lê JSON), Edge (billing-constants.ts), Play runbook e ficha alinhados. Coberto por tests/trial-parity.test.js.

FEITO Soft paywall local

LOCAL_AI_FREE_USES=5 para OCR/previsão no modo local. Export e alertas básicos seguem livres offline (offline-first).

FEITO Stripe lifecycle no path Supabase

Edge stripe-checkout, stripe-portal, stripe-cancel, org-invite. Client via SUPA_BILLING.invoke. notify() com Resend opcional.

FEITO Business + Equipe

SHOW_BUSINESS_PLAN: true. Card Equipe no perfil: listar, convidar, copiar link, revogar, remover. Aceite via ?invite= + RPC fp_accept_org_invitation.

FEITO Paridade maxUsers + gates nuvem

FREE=1, PRO=2, BUSINESS=∞ em JSON/billing/middleware. Insights avançados e Open Finance gated no FREE nuvem.

FEITO Dunning / trial ending no app

BILLING.getLifecycleAlert → banner dashboard para PAST_DUE, trial ≤3 dias e cancelamento agendado, com CTA portal/planos.

FEITO Ficha Play honesta

docs/play-store-ficha.md sem “sem cadastro”, com trial 7d e preços. Teste de honestidade cobre a ficha.

FEITO Wiring + OpenAPI revoke + templates e-mail

npm run check:billing (CI). OpenAPI DELETE /orgs/{orgId}/invitations/{invitationId} + testes OrgService.revokeInvitation. Contratos Resend em edge-email-templates.test.js. levantamento-pro-vs-local.md atualizado (soft IA + dual path).

FEITO Honestidade soft IA + invite sem bypass

Copy do paywall local deixa de prometer “todos os recursos”. Soft AI coberto por testes runtime. org-invite 404/503 falha explícita (sem insert direto). Contratos Edge portal/cancel/invite no CI.

FEITO Funil soft + dual path Supabase-first

Paywall abre offline (sem Assinar). Insights consomem soft AI. Banner local ≤2 usos. Portal/cancel/checkout preferem Edge mesmo com Express URL. Play Billing tests + E2E billing-smoke.

FEITO Upsell alertas + Play details + invite pós-login

FREE nuvem ganha teaser de alertas avançados. getProductDetails no plugin/bridge. Restore vazio não finge sucesso. ?invite= consome no SIGNED_IN.

OPS Deploy remoto ainda necessário

Código pronto; produção depende de supabase db push, deploy das functions e secrets (RESEND_API_KEY, Stripe, Play). Checklist: docs/deploy-billing-edge.md. Sem org-invite deployada, convites falham de propósito.

P2 Arquitetura dual Express × Supabase

APK Capacitor usa Supabase; Express permanece para legado/dev. Docs e rotas alinhados; dualidade ainda é custo de manutenção.

P2 Sem E2E de compra real

Suíte unitária + check:billing. Falta instrumented Play Billing e checkout Stripe sandbox ponta a ponta.
