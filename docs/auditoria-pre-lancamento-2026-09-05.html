6. Bugs / riscos encontrados

P0 RISK-01 — Fail-open Free até carregar chunk conta

Módulo: Billing / quotas · Impacto: Free ultrapassa limites no AAB

Descrição: billing.js entra no lazy chunk conta. Call sites usam typeof BILLING !== 'undefined' && !BILLING.guardQuota(...) — se o módulo não carregou, a guarda é ignorada.

Como reproduzir: TESTE MANUAL NECESSÁRIO — instalar AAB, nunca abrir Config, criar 6+ contas/orçamentos/metas offline.

Esperado: bloqueio Free. Encontrado (código): caminho permite até Config/Resumo nuvem.

Evidência: scripts/bundle-app.cjs; js/assinaturas.js, init-form.js, previsao.js; tests/lazy-chunks.test.js

Recomendação: carregar billing.js no bundle crítico OU fail-closed quando ausente.

P1 RISK-02 — Spoof de plano offline

Descrição: getTier() lê config.plano local; usuário pode setar pro e desligar quotas offline.

Impacto: esperado em app local-first; aceitável se produto assume trust no aparelho. Documentar honestamente.

Evidência: js/billing.js getTier / shouldEnforceLimits

P1 RISK-03 — Quotas SQL incompletas

Descrição: Triggers cobrem Account/Budget; goals/bills/OCR/AI/PDF sem trigger equivalente.

Evidência: supabase/migrations/20260901150000_quota_enforcement.sql, quota_v2 sem novos triggers

P1 RISK-04 — Revoke Play depende de RTDN ou Config

Descrição: Lógica !entitled → revoke existe; reconciliação só no chunk Config (≤1×/6h). Sem RTDN live, Pro pode persistir após cancelamento.

Evidência: play-billing.ts, init-billing.js _reconciliarPlay, runbook

TESTE MANUAL NECESSÁRIO — cancelar assinatura Play e não abrir Config.

P1 RISK-05 — RTDN produção não verificável só pelo repo

TESTE MANUAL NECESSÁRIO — Pub/Sub + OIDC + logs Edge no projeto GCP/Supabase.

P2 BUG-06 — Cap OCR só em localStorage

Limpar storage reseta contador Free 5/mês. Evidência: billing.js _OCR_USES_KEY

P2 RISK-08 — Sessão Supabase em localStorage

XSS ⇒ roubo de sessão. Mitigações CSP/escape existem; residual. TESTE MANUAL CSP build prod.

P2 TEST-FAIL — 8 testes frontend vermelhos

suite-integrity (paths), auth-recuperacao, play-store-fase2/3, marca-nome-unico — drift, não regressão de ledger nesta amostra.

9. Free vs Pro

Fonte canônica: config/plan-limits.json (paridade testada com JS e SQL numérico).

Free (destaques)

  • Lançamentos ilimitados; histórico 3 meses
  • ≤5 contas, orçamentos, bills, assinaturas; 1 meta; 3 recorrentes
  • OCR 5/mês; CSV sim; PDF/IA/OF/alertas avançados não
  • Welcome trial Pro 14d; SKU trial 7d

Pro

  • Capacidade/profundidade ilimitadas
  • IA, PDF, Open Finance, alertas avançados, team (2 users)
  • Business existe no mapa mas oculto na vitrine

Conclusão: regras bem definidas; enforcement no AAB comprometido por RISK-01 até carregar billing.
