7. Gaps abertos (detalhe)

P1 UPG-01 — Mensal → anual sem CTA

Quem já é Pro mensal vê “Plano atual” mesmo com o toggle em Anual. O plugin nativo não passa SubscriptionUpdateParams. Concorrentes maduros (Speak, Todoist, Google One) oferecem “Mudar para anual”; Mobills Android ainda força cancel→reassinar.

Impacto: perda de LTV (129,99 vs ~203,88/ano). Não bloqueia closed testing.

P1 RISK-02 — Spoof local de Pro

Editar/importar backup com plano: "pro" pode liberar features no cliente offline. Escrita na nuvem continua limitada pelo tier da Subscription (SQL).

Mitigação parcial aceitável para beta; para wide open, amarrar features sensíveis a BILLING._cache.subscription verificada.

P0 ops RISK-05 — RTDN

Sem Pub/Sub → play-rtdn, cancel/refund/expire dependem do reconcile no boot (rede de segurança). Aceitável em beta curto; frágil em produção se o usuário não reabre o app.

P1* RISK-03 — Migrations live

Arquivos presentes: 20260905180000_quota_v3_triggers_profundidade.sql, 20260906120000_fp_plan_tier_precedencia.sql, 20260906130000_quota_userconfig_sem_travar.sql. Status no projeto Supabase: não confirmado nesta sessão.

8. Testes manuais obrigatórios antes do wide open

  1. AAB Free: tentar Metas/OCR/export Pro sem abrir Config — deve bloquear.
  2. Android + nuvem: matar app → reabrir → entitlement atualiza sem Config (RISK-04).
  3. License tester: comprar Pro mensal → badge Pro → sync.
  4. Cancelar na Play → Pro permanece + “mais X dias (cancelado)”.
  5. Device limpo: Restaurar compras.
  6. Airplane mode com sessão salva: entrar (PIN/biometria); sem sessão: bloquear senha.
  7. Importar backup com plano:pro em conta Free → sync deve falhar nas cotas SQL.
  8. npx supabase migration list — todas as migrations de quota aplicadas.
  9. Disparar evento RTDN de teste (cancel/expire) e ver log da Edge Function.
  10. Paywall Pro mensal → toggle Anual: documentar comportamento atual (sem CTA) até o fix.
  11. Build dist/: CSP sem localhost; preços Play = 16,99 / 129,99.
  12. Secrets prod: SA Play presente; PLAY_SANDBOX_ENABLED ausente.
