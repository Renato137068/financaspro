Status das recomendações

FEITO Trial unificado em 7 dias

FEITO Soft paywall local (OCR/previsão)

FEITO Portal/cancel Stripe no path Supabase

Edge stripe-portal + stripe-cancel; cliente chama via SUPA_BILLING.invoke. Footer do paywall mostra botões também no path Supabase.

FEITO Business no paywall + teamFeatures no backend

SHOW_BUSINESS_PLAN: true. Convite de membros exige teamFeatures (402 no FREE). UI de equipe no perfil.

FEITO maxUsers canônico

plan-limits.json + billing.js + middleware: FREE=1, PRO=2, BUSINESS=∞ (alinhado ao seed casal).

FEITO Gates nuvem FREE extras

Insights avançados (projeção, anomalias, poupança…) e Open Finance gated por aiFeatures/openFinance.

FEITO UI de equipe / convites

Card Equipe no perfil, modal com membros/pendentes, convite por e-mail (link 7 dias), aceite via ?invite= + RPC fp_accept_org_invitation. FREE abre paywall; Pro respeita maxUsers=2.

FEITO E-mails Resend + org-invite

notify() envia via Resend quando RESEND_API_KEY está setada. Edge org-invite cria convite e dispara e-mail; cliente faz fallback para insert direto se a function não existir.
