Entregue neste lote

  • 2FA TOTP Supabase — enroll/verify no Perfil, gate AAL2 no login/biometria/boot (supabase.js, init-2fa.js, authController.js)
  • Privacidade — TOTP documentado como opcional (privacidade.html)
  • Footer auth — copy honesto (local vs nuvem, cifragem opcional)
  • CSP prod — connect-src sem localhost no dist/
  • Supabase env — override opcional no build (inject-supabase-env.cjs)
  • Billing UX — portal/cancel Stripe bloqueados no path Supabase morto
  • FLAG_SECURE cedo — PIN bloqueia screenshot antes do pin.js carregar
  • E2E markup — auth-supabase-ui.spec.cjs cobre TOTP + skip corrigido

Residuais abertos

  • E2E login real — precisa E2E_SUPABASE=1 + credenciais; conta sem MFA
  • assetlinks.json — copiado para dist/.well-known/, mas app.financaspro.com retorna 500
  • MFA no painel — TOTP exige toggle no projeto Supabase; fail-open se desligado
  • Express legado — backend/ e rotas /api/v1/auth/* ainda no repo (inerte no APK)
  • Sessão/desbloqueio — re-pede senha ao retomar app (intencional, mas confunde)
  • Tokens — refresh Supabase em localStorage + Keystore biometria (não HttpOnly)

Achados por quesito (nota atual)

85 Login e-mail → senha

Duas etapas, loading no botão, gate MFA pós-senha, modal biometria após fechar overlay. Voltar no TOTP faz logout AAL1.

82 Biometria Android

AUTH_BIOMETRIC.disable() no logout; oferta pós-login fora do overlay; gate MFA também após biometria.

78 2FA / TOTP (+23 desde v11.3.9)

Implementação real via auth.mfa.*: enroll com QR, verify no login, unenroll no Perfil. Depende de MFA habilitado no dashboard Supabase.

82 Recuperação de senha

Deep link app.financaspro.com, formulário nova senha, consumeAuthCallback. App Link ainda não verificado em produção (assetlinks offline).

82 Segurança da autenticação

Reauth na exclusão, FLAG_SECURE em auth/PIN, MFA AAL2, RLS Supabase. Tokens ainda acessíveis ao JS (limite estrutural do cliente Supabase).

68 Sessão e desbloqueio

Fluxo bancário “confirme sua identidade” ao retomar app permanece. MFA no boot melhora segurança, mas UX ainda exige senha com sessão ativa.

68 Testes automatizados

auth-fase3, auth-hardening, build-mode-residual, E2E markup. Falta login E2E Supabase e teste de plugin biometria nativo.

68 Arquitetura Express vs Supabase

APK usa só Supabase (_apiAtiva false no Capacitor). Express permanece no monorepo; env inject reduz hardcode, mas não unifica arquitetura.
